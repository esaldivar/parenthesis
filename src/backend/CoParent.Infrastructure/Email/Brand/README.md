# Email brand asset

`parenthesis-icon-180.png` is an unchanged copy of the approved icon export
`docs/design/assets/parenthesis-icon-180.png` (Variation 1, see `docs/design/BRANDING.md`). Emails embed it inline
(`cid:parenthesis-icon`) because most email clients don't display SVG. Never redraw, recolour or edit it; if the
approved export changes, copy the new file here unchanged.
