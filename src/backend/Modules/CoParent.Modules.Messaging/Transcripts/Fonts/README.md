# Transcript fonts

Noto Sans Regular and Bold, embedded in the API so PDF transcripts render the same everywhere (the container has no
system fonts). Copyright 2022 The Noto Project Authors, licensed under the SIL Open Font License 1.1 (`OFL.txt`).
Taken from the `@expo-google-fonts/noto-sans` 0.4.2 npm package, which repackages Google Fonts' static instances.
They cover Latin, Greek and Cyrillic; other scripts and emoji print as empty boxes.
