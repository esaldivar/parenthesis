# Security Policy

This application handles data about families and children. Please report vulnerabilities privately.

## Reporting a vulnerability
Use GitHub's **private vulnerability reporting** on this repository (Security → Report a vulnerability). Do not open a public issue.

Please include the affected component, steps to reproduce and the impact. Use synthetic data only in reports.

## Scope
- Tenant isolation (accessing another family's data)
- Authentication and session handling
- Access to private media (photos, artwork, diaries)
- Approval-workflow bypasses
